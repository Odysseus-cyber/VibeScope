# 五分钟演示脚本

提前运行 `./scripts/start.sh demo`。先确认页面标注演示模式，说明这里的可控样本用于演示系统能力，不是真实增长排行榜。

1. **0:00—0:45，趋势总览。** 切换时间窗口，讲清创建与收录的差异。展示类别和工具分布，解释工具多标签导致比例之和可能大于 100%。
2. **0:45—1:40，发现与详情。** 筛选一个应用类别，按七天净增排序，打开项目查看曲线、讨论和来源；导出当前筛选结果的 CSV。
3. **1:40—2:30，AI 证据。** 查看一条分类依据，说明“带 AI 功能”与“用 AI 编程完成”是两个概念。进入候选复核，演示修改类别/工具，检查人工覆盖状态。
4. **2:30—3:20，任务与质量。** 查看任务状态、采集覆盖及数据新鲜度；解释重复采集如何通过来源 ID 和每日唯一键实现幂等，缺失快照为什么显示未知。
5. **3:20—4:15，AI 周报。** 生成并打开报告，对照报告里的数字与总览，查看事实和来源。没有模型配置时介绍当前是模板摘要，接入模型后仍复用同一事实集。
6. **4:15—5:00，工程实现。** 打开架构图，从页面指标追到 ADS、DWS、每日快照和原始 JSON；展示 dbt 测试和后端测试的实际运行输出。

## 常见现场情况

- live 没有完整七天历史：展示首次收录时间和未知增长，解释为什么不拿当前总星标冒充增长。
- API 限流或网络不可达：打开任务记录解释退避与覆盖状态，继续用独立 demo 模式展示功能。
- 未配置 LLM：展示规则分类和模板周报，说明真实模型调用入口及评估方法，避免称其为模型实测效果。
- 演示修改了分类：类别/工具分布会重算，历史图使用当前统计池口径，说明这一取舍。
